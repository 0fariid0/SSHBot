Emergency fix for: ModuleNotFoundError: No module named 'pkg_resources'

Cause:
Python 3.12 virtualenvs do not always include setuptools/pkg_resources by default.
python-telegram-bot==13.15 imports APScheduler 3.x, and APScheduler needs pkg_resources.

Run this on the server as root:

systemctl stop sshbot || true
runuser -u sshbot -- /opt/sshbot/venv/bin/python -m ensurepip --upgrade || true
runuser -u sshbot -- /opt/sshbot/venv/bin/python -m pip install -U --force-reinstall pip wheel "setuptools<81"
runuser -u sshbot -- /opt/sshbot/venv/bin/python -m pip install -U "setuptools<81" "APScheduler==3.6.3" "tzlocal<3" "urllib3<2" "python-telegram-bot==13.15" certifi paramiko cryptography pyte
runuser -u sshbot -- /opt/sshbot/venv/bin/python - <<'PY'
import pkg_resources
import telegram.ext
import paramiko
import cryptography
import pyte
print('imports ok')
PY
systemctl restart sshbot
systemctl status sshbot --no-pager
journalctl -u sshbot -n 80 --no-pager

Installer change:
The install.sh in this ZIP has been updated to install/pin setuptools<81 and APScheduler==3.6.3, then test imports before starting the service.
